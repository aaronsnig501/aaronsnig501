# Aaron Sinnott
### Senior Software Developer · Loch Garman, Éire

I build distributed systems at scale by day and infrastructure for Irish language revival by night.

At work I'm a senior developer at 888Spectate, leading development on some of the platform's most critical systems — feed panic handling, bet placement decomposition, and distributed backends that have to be right. A decade of production Python, with Java, Kafka, AWS, and whatever else the problem needs.

Outside of work I'm building [Misneach](https://github.com/misneach-site/misneach) — a platform to normalise Irish language use in everyday commercial spaces. Full-stack, AWS-deployed, solo-built. I'm also leading [Gaeilge sa Chonsol](https://github.com/aaronsnig501/gaeilge-sa-chonsol) — an open source project translating retro games into Irish. Spyro the Dragon is 50% complete. Because language revival can happen anywhere, including a 1998 PlayStation disc.

I write about Irish language, identity, and colonialism at [Substack](https://aaronsinnott.substack.com/).
